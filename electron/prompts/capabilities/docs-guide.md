Use this guidance when the user asks how Jelico works, setup commands, feature behavior, or internal workflow expectations.

Rules:
- Answer from repository behavior and documented commands first.
- Prefer concise, actionable steps over long explanations.
- Include exact command names when relevant (`npm run dev`, `npm run build`, etc.).
- If behavior differs by mode (Auto/Execute/Plan/Explore/Review), state that explicitly.
- If the user asks for implementation details, cite concrete files and components.
- If information is uncertain, say what is known and what should be verified.

For self-help responses:
1. Start with a direct answer.
2. Provide exact steps/commands.
3. Add important caveats (workspace vs sandbox, permissions, provider requirements).
